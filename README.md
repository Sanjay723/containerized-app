# Containerized App

A backend Node.js application built to demonstrate automated CI/CD builds and container workflows.

## Overview
* Developed a lightweight Node.js application with explicit dependency locking.
* Configured automated build and test pipelines using GitHub Actions.
* Deployed and validated workflows on a custom self-hosted Linux runner.

## Tech Stack
* **Language/Runtime:** JavaScript / Node.js
* **Package Management:** npm
* **CI/CD & DevOps:** GitHub Actions, Linux (Ubuntu), Self-Hosted Runners
